# AWS Cloud Engineer Interview Preparation - 15 Day Plan

## Overview
This repository contains a comprehensive 15-day study plan designed to prepare you for an AWS Cloud Engineer interview. The plan covers all essential AWS services including EC2, S3, VPC, IAM, Lambda, RDS, CloudFormation, and CloudWatch with daily schedules, practice tasks, hands-on exercises, and GitHub integration.

## Services Covered
- **EC2** (Elastic Compute Cloud)
- **S3** (Simple Storage Service)
- **VPC** (Virtual Private Cloud)
- **IAM** (Identity and Access Management)
- **Lambda** (Serverless Computing)
- **RDS** (Relational Database Service)
- **CloudFormation** (Infrastructure as Code)
- **CloudWatch** (Monitoring and Logging)

## How to Use This Plan
1. **Daily Routine**: Follow the schedule for each day (Study → Practice → Hands-on → GitHub)
2. **Hands-on Exercises**: Complete all labs using your AWS Free Tier account
3. **GitHub Integration**: Document your learning and push code/scripts daily
4. **Review**: Use weekends for review and practice question reinforcement

## Prerequisites
- AWS Free Tier account
- GitHub account
- Basic Linux/CLI knowledge
- Text editor (VS Code recommended)
- Internet access

## Daily Schedule Template
Each day follows this structure:
- **Study** (60 min): Read documentation, watch videos, take notes
- **Practice** (30 min): Answer multiple-choice questions
- **Hands-on** (60 min): Complete practical exercises/labs
- **GitHub** (15 min): Document learning, push code/notes to repository

## Getting Started
1. Clone this repository: `git clone https://github.com/abhinavpadige4/aws-interview-prep-15day-complete.git`
2. Start with Day 1: EC2 Fundamentals
3. Complete each day's activities in order
4. Push your daily progress to GitHub
